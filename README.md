# DariTap (демо нұсқа)

Дәріні іздеу, бағасы мен қолжетімділігін және сатушы дәріхананың лицензия мәртебесін көру, дәріханадан алып кетуге тапсырыс беру платформасының **демонстрациялық** нұсқасы.

## Іске қосу

Қажет: Node.js 18 немесе одан жаңа нұсқасы. `npm install` қажет емес, себебі сыртқы тәуелділік жоқ.

```bash
cd daritap
npm start              # http://localhost:3000
npm run reset          # демо деректерді бастапқы күйге қайтару (data/ папкасы тазаланады)
PORT=8080 npm start    # басқа порт
```

Демо аккаунттардың бәрінің құпиясөзі `demo123`:

| Логин | Рөлі |
|---|---|
| `customer` | Сатып алушы |
| `seller1` | «Демо дәріхана А» сатушысы |
| `seller2` | «Демо дәріхана Б» сатушысы |
| `reviewer` | Тексеруші |

## Интернетке шығару (Render, тегін)

1. https://render.com сайтына GitHub аккаунтыңызбен кіріңіз.
2. **New → Blueprint** батырмасын басып, `daritap` репозиторийін таңдаңыз. Render `render.yaml` файлын өзі оқиды.
3. **Apply** басыңыз. Бірнеше минуттан кейін сайт `https://daritap-xxxx.onrender.com` сияқты мекенжайда ашылады.

Тегін жоспардың шектеулері:
- 15 минут ешкім кірмесе, сервер «ұйықтайды», келесі ашылуы шамамен 1 минутқа созылады.
- Диск уақытша: сервер қайта іске қосылғанда өтінімдер, тапсырыстар және жүктелген файлдар демо күйіне қайтады.
- Демо аккаунттардың құпиясөздері ашық, сондықтан сайтқа кірген кез келген адам тексеруші бола алады. Сайтқа нақты құжаттар мен жеке деректерді жүктемеңіз.

## Толық сценарийді тексеру

1. Екі демо дәріханаға **ДЕМО лицензия** алдын ала мақұлданған, сондықтан тауарларды бірден себетке қосуға болады (қоймада жоқ тауарлардан басқасы). Лицензия нөмірі мен беруші органы «ДЕМО» деп белгіленген — бұл нақты лицензия емес.
2. `seller1` ретінде кіріңіз. **Лицензияны тіркеу** бөліміндегі форманы толтырып, PDF/JPG/PNG файлын жүктеңіз. Өтінім **«Тексерілуде»** мәртебесіне өтеді.
3. `reviewer` ретінде кіріп, өтінімді ашыңыз да, құжатты қарап **Мақұлдаңыз** немесе себебін жазып **Қабылдамаңыз**.
4. Өтінім қабылданбаса, сатушы оны түзетіп, қайта жібере алады.
5. Мақұлданған соң А дәріханасының тауарларында **«Лицензия расталған»** белгісі пайда болады, оларды себетке қосуға болады.
6. `customer` ретінде тапсырыс беріңіз. Рецептпен берілетін тауар болса, рецепт файлын жүктеу керек. Сатушы рецептті **растамайынша** тапсырыс «Алып кетуге дайын» немесе «Берілді» күйіне өтпейді.

## Құрылымы

```
server.js        HTTP сервер, API, рөлдік қорғаныс, файлдарды тексеру
seed.js          демо деректер (лицензиясыз басталады)
config.json      сайт операторының лицензиясы (әзірге null)
public/          интерфейс (index.html, styles.css, app.js, i18n.js)
data/            db.json және uploads/ (автоматты жасалады, жалпыға ашық емес)
```

## Не демо, не нақты

- **Нақты жұмыс істейді (жергілікті түрде):** іздеу, сүзгілер, себет, формаларды тексеру, рөлдер мен сессиялар, файл жүктеу (түрі файлдың мазмұны бойынша тексеріледі, көлемі 5 МБ-қа дейін), өтінімнің тексеруші кезегіне түсуі, мақұлдау және қабылдамау, тапсырыс пен оның мәртебесі.
- **Демо:** дәріханалар, бағалар, қойма қалдығы және рецепт белгілері. Өндіруші, нұсқаулық және тіркеу куәлігі әдейі бос қалдырылған. Тапсырыс нақты дәріханаға жіберілмейді, төлем де жоқ. Лицензия мемлекеттік тізіліммен салыстырылмайды.
- Сайт операторының лицензиясын көрсету үшін `config.json` файлына мына үлгімен нақты деректерді жазыңыз:
  `{"operatorLicense": {"orgName": "...", "number": "...", "issuer": "...", "issueDate": "YYYY-MM-DD"}}`.
  Тек толтырылған өрістер ғана көрсетіледі.

## Өндіріске шығару үшін қажет интеграциялар

- Нақты дерекқор (мысалы, PostgreSQL) және файл қоймасы (шифрланған S3 тәрізді қойма).
- Нақты тіркелу мен аутентификация (SMS/eGov/ЭЦҚ), құпиясөз саясаты, кіру әрекеттерін шектеу, HTTPS.
- Лицензиялар мен дәрілердің тіркеуін мемлекеттік тізілімдермен салыстыру (elicense.kz, ДЗ мемлекеттік тізілімі және т.б.).
- Ресми нұсқаулықтардың көзі, дәріханалардың нақты каталогы мен қойма қалдығы (API/1С).
- Электрондық рецептті тексеру, төлем жүйесі, SMS хабарламалар.
- Заңдық тексеру: дәріні қашықтан сату және дербес деректерді қорғау талаптары.
